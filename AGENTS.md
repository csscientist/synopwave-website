# SynopWave Website Instructions

## Mission

- Build a fast, accessible static company website for SynopWave.
- Prioritize clear content, responsive design, and simple navigation.

## Implementation

- Keep the site static unless the requested feature requires otherwise.
- Prefer semantic HTML, modern CSS, and minimal JavaScript.
- Reuse existing styles and components before adding new ones.
- Keep changes small and limited to the requested milestone.
- Do not add frameworks, dependencies, services, or infrastructure without a current need.

## Quality

- Support mobile and desktop layouts.
- Preserve accessibility, keyboard navigation, and readable contrast.
- Optimize images and avoid unnecessary client-side code.
- Run the project's available formatting, linting, and tests before committing.

## Git

- Commit completed work.
- Never push unless explicitly requested.
